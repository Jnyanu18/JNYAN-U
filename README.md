## 📦 Featured Projects

### 🌾 CSG_12 — Domain Intelligence Engine
> *AI confidence validation and adaptive calibration architecture*

Built a system that sits on top of any AI model and learns when to trust its confidence scores. Proved on 444 real images that naive AI calibration destroys accuracy by 18 percentage points. The safety mechanism catches this automatically.

**Key finding:** Naive adaptation degrades ±1 accuracy from 68.5% → 49.8%. Safety-first conditional adapter preserves it at 70.8%.

`Next.js 14` `MongoDB Atlas` `Groq API` `Gemini Flash` `TypeScript` `Vercel`
